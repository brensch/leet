# Find Median from Data Stream

## Prompt
The median is the middle value in an ordered integer list. If the size of the list is even, there is no middle value, and the median is the mean of the two middle values.

For example:

- For `[2, 3, 4]`, the median is `3`.
- For `[2, 3]`, the median is `(2 + 3) / 2 = 2.5`.

Implement the `MedianFinder` type:

- `Constructor() MedianFinder` initializes the object.
- `AddNum(num int)` adds the integer `num` from the data stream to the data structure.
- `FindMedian() float64` returns the median of all elements so far.

## Target
Implement `Constructor`, `AddNum`, and `FindMedian` in `solution.go`.
